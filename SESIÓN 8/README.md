# SESIÓN 8: PROYECTO DEL CURSO "CASO SÚPER FRESCO"

Esta sección es un proyecto práctico que aplica los conocimientos del curso, enfocándose en la creación de un informe completo para el "Caso SuperFresco".

## Objetivos de la Sección:

* **Importar y Transformar Datos**: Adquirir la habilidad de cargar datos de diversas fuentes y limpiarlos/transformarlos eficientemente para su análisis.
* **Diseñar Modelos de Datos Robustos**: Aprender a crear y optimizar modelos de datos relacionales, estableciendo las conexiones adecuadas entre las tablas.
* **Aplicar DAX para Cálculos Avanzados**: Dominar el lenguaje DAX para desarrollar columnas calculadas y medidas que permitan obtener insights profundos y personalizados.
* **Construir Informes Interactivos y Efectivos**: Desarrollar la capacidad de diseñar páginas de informe visualmente atractivas y funcionales (Resumen Ejecutivo, Mapa, Tiendas, Marcas).
* **Mejorar la Experiencia del Usuario (UX) del Informe**: Implementar elementos de navegación personalizados, marcadores y paneles de segmentación para hacer los informes más dinámicos y fáciles de usar.
* **Consolidar Habilidades en Proyectos Reales**: Aplicar de forma integrada todas las competencias adquiridas en el curso a través de un caso de estudio completo.

## Contenido Clave:

1.  **Introducción y Preparación**: Presentación del caso y notas sobre la importación de datos.
2.  **Importación y Transformación de Datos**: Tareas para limpiar y preparar los datos.
3.  **Creación del Modelo de Datos**: Establecimiento de relaciones entre tablas.
4.  **Columnas Calculadas y Medidas con DAX**: Uso de DAX para cálculos avanzados.
5.  **Diseño de Páginas del Informe**: Construcción de páginas de informe como Resumen Ejecutivo, Mapa, Tiendas y Marcas.
6.  **Interactividad y Navegación del Informe**: Implementación de navegación personalizada, marcadores y paneles de segmentación para mejorar la interactividad.
7.  **Conclusión**: Resumen final del curso y próximos pasos.

Cada tarea de la sección incluye su respectiva solución en video, a menudo acompañada de recursos descargables para seguir la práctica.
